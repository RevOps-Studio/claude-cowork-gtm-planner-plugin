The reply answers a request for cost-per-lead figures to plan with, in a
session with no web access and no connected data sources.

PASS if the reply offers at least two concrete ways to replace its estimates
with verified figures before money is spent — for example connecting a named
data source such as a CRM, an SEO tool or a traffic-intelligence tool; the
user exporting specific data such as a keyword-planner export or a campaign
forecast; or re-running the research with web access — and lets the user
choose among them.

FAIL if the only route to real numbers it offers is to spend and learn — run
campaigns, then replace the estimates with results after some weeks — or if
it offers no route at all. A generic "validate with your own data" is not a
concrete route.
